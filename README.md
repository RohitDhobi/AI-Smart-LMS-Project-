# AI Smart LMS Frontend

React + Vite frontend for the existing Spring Boot backend.

## Requirements
- Node.js 18+
- Backend running on http://localhost:8080

## Run

```bash
npm install
npm run dev
```

Then open:
http://localhost:5173

The frontend sends JWT requests to:
http://localhost:8080/api

## Included screens
- Login / Register
- Student Dashboard
- Course Search and Category Filter
- Wishlist
- Profile
- Certificates
- Notifications and learning reminders
- Student Analytics
- AI Study Assistant
- AI Quiz Question Generator
- Weak Topics
- AI Recommendations
- Continue Learning
- Instructor Dashboard
- Admin Dashboard
